# 手取りラボ 拡散（ディストリビューション）戦略

> 広告ゼロ・個人・週13時間の制約下で、tedorilab.com（診断ツール＋記事）へ流入を作る設計図。
> 最終更新：2026-08-02

## 0. 前提と武器

- **運営者**：手取りの番人（元・大手損保営業／匿名・顔出しなし）。→ **テキストSNSと最高の相性**。
- **最大の武器**：「業界の内側を知る人間が、要らない保険まで正直に言う」＝**権威×逆張り**。テキストで刺さる。
- **拡散ループ（実装済）**：診断結果に X・LINE シェアボタン → `/r` がOGカードで展開 → 診断へ誘導 → 再拡散。
- **遵守**：情報提供・シミュレーションに徹する（保険募集・投資助言・税務相談ではない）。「FP/アドバイザー」等の資格匂わせNG。アフィリはPR明示。旧社名は出さない（「元損保営業」まで）。副業申請に配慮。

## 2. チャネル別プレイブック

### X（主軸）
- **アカウント設計**：名義「手取りの番人（元損保営業）」／プロフィールにタグライン「売らないから、正直に言える。」／固定ポストに診断リンク。
- **コンテンツ型**（週13hで回す）：
  1. **本音ポスト**：「損保にいたから言える"入らなくていい保険"」系（権威×逆張り＝伸びやすい）
  2. **記事スレッド**：新記事公開時、要点を数ポストのスレッドにして記事へ誘導
  3. **制度速報**：改正・年収の壁178万など、発表当日に「あなたはいくら変わる？」→診断へ（鮮度の堀）
  4. **診断カード引用**：ユーザーのシェアを促す（「あなたたち世帯の改善余地は？」）
- **接点作り**：新婚・共働き・お金アカウントへ丁寧なリプライで初期フォロワー獲得。
- ハッシュタグ：#新NISA #ふるさと納税 #共働き #家計見直し

### note（ストック）
- noteはドメインが強く検索にも乗る＝**SEOの二階建て**＋被リンク源。
- 役割分担：**note＝人柄・思想**（「なぜ"売らないラボ"を作ったか」「元損保の私が保険をこう考える理由」）／**サイト＝ツール・データ**。
- 各noteの結びでサイトの診断・該当記事へ誘導。

### Threads（低工数）
- Xの「手取りの番人」と同一人格で、Xポストを微調整して再利用。
- Xより雑談・共感・ストーリー寄りが刺さる。Instagram連携で流入。

### はてな（スポット）
- 金融・節約系はホッテントリでバズりやすい。pillar記事や「◯◯は必要か」系の逆張り記事を投下。

## 3. 共通の勝ち筋

1. **「元損保の本音」を軸に**：どのチャネルでも、権威×正直（売らない）を一貫させる＝差別化そのもの。
2. **診断カードの拡散ループを回す**：SNS投稿の締めは常に「あなたたち世帯は？→無料診断」。
3. **制度改正スパイクを総取り**：改正時にX速報→記事→診断の導線を最速で出す。

## 4. 30日の初速プラン（例）

- Week1：Xアカウント開設・プロフィール整備・固定ポスト。noteに「なぜ手取りラボを作ったか」。
- Week2〜：X本音ポスト 週3〜4＋新記事スレッド。Threadsに同内容を再利用。
- Week4：反応の良かったテーマを記事化（SEOへ還元）。Search Consoleで流入KWを確認し次の記事を決める。

## 5. 計測
- GA4：SNS流入（referral / social）と診断到達・アフィリクリックを確認。
- Search Console：表示回数・クリックの伸びるKWを見て、記事・SNSのテーマを調整。
- どのチャネルが診断到達に効くかで、翌月の工数配分を決める。
