# ブランド定義 — 手取りラボ / 手取りの番人

> `docs/brand.md`。CLAUDE.md / spec.md と併せて、実装のコピー・トーンの基準にする。

## ポジショニング（2026-08-02 更新・重要）
- **主役 = 横断の全体最適**：保険・ふるさと納税・iDeCo・NISAを**まとめて**見て、手取りの"適正"を効果額順に。単発の計算機との差別化はここ（CLAUDE.md 舵②）。
- **中立に開く**：夫婦・世帯に限定せず「**ひとりでも、夫婦の世帯合算でも**」。個人リーチを最大化する。
- **ただし世帯は"深さ"として一級機能で温存**：遺族年金・二人分枠を織り込む世帯モードは、最も真似しにくいエンジンの核＝堀。夫婦・共働きのSEOも維持。
- → コピーは中立×横断を主にする。「夫婦」「世帯」は排他的な見出しには使わず、深い機能・特定セグメントとして活かす。

## タグライン
- **メイン**：「売らないから、正直に言える。」
- **ヒーロー・サブ**：「保険・ふるさと納税・iDeCo・NISAを、まとめて。」（＝横断の全体最適を主役に）

## プロフィール文

### 短文（SNS/note）
元・大手保険会社の営業。"売る側"から"売らない側"へ。保険・ふるさと納税・iDeCo・NISAを横断して手取りを最適化する『手取りラボ』を運営。中の人＝手取りの番人。

### About（運営者情報ページ）
「手取りラボ」を運営している、手取りの番人です。
新卒で大手の保険会社に入り、[◯年間、]保険の営業をしていました。売る側にいたからこそ分かります——世の中には、必要のない保障や、割高なまま放置された保険がたくさんあります。
だから僕は、何も売りません。代わりに、保険・ふるさと納税・iDeCo・NISAを横断してお金を丸ごと見て、「手取りがいちばん増える順番」で打ち手を並べます。要らない保険は「解約でいい」、今のままで十分なら「何もしなくていい」と正直に言います。
ひとりでも、夫婦で世帯を合算しても使えます。特に結婚は、二人のお金を初めて一つにする大きなタイミング。ここで土台を整えるだけで、生涯の手取りは大きく変わります。「手取りラボ」は、その最適化を"円"で見える化するツールです。
※当サイトは一般的な情報提供・シミュレーションであり、特定商品の勧誘や個別の投資・税務の助言ではありません。

> [◯年間] は事実に合わせて記入（盛らない）。

## トーン & ボイス
- 正直・率直。専門家だが上から目線にしない。
- **売り込まない**。「今のままでいい」「解約でいい」も言う。
- 断定しすぎず、**数字（円）で語る**。
- お金に向き合う人（単身・共働き・新婚〜世帯）に寄り添う温度。堅すぎない。

## 遵守ルール（重要）
- これは**情報提供・シミュレーション**。投資助言・保険募集・税務相談ではない。
- 「FP」「アドバイザー」等、**資格を匂わせる表記を使わない**。
- アフィリ導線には**PR/広告である旨を明示**（景表法・ステマ規制）。
- 運営者情報は屋号＋最低限の法定表記（実名/住所の扱いは商用化時に確定）。
