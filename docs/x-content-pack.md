```
ふるさと納税、実は“やってない人”が一番損してる。
限度額の範囲なら、実質2,000円で返礼品。共働きは二人分の枠。
使わなかった枠は、毎年ドブに捨ててるのと同じです。
→ https://tedorilab.com/articles/furusato-guide
#ふるさと納税
```

## 4. 記事誘導スレッドの雛形（新記事公開時）

```
【1/5】（記事の一番刺さる結論を1文で。例）「独身に大きな死亡保険は、基本いりません。」

理由を3つに絞って👇

【2/5】理由①：死亡保険は“遺された扶養家族”のためのもの。扶養がいなければ必要なのは葬儀代程度。

【3/5】理由②：医療は高額療養費でカバー。貯蓄があれば医療保険も過剰になりがち。

【4/5】理由③：本当に備えるべきは“働けないリスク”。まずは生活防衛資金。

【5/5】くわしくは記事に。自分の適正は“円”で診断できます（無料・ログイン不要）。
記事▶ [記事URL]
診断▶ https://tedorilab.com/diagnose
```

## 5. 運用ルール（チェックリスト）

- **頻度**：本音ポスト 週3〜4本＋新記事スレッド。Threadsに同内容を再利用（工数を増やさない）。
- **締めは常に導線**：「あなたは？→ 無料診断 / 記事」で終える。
- **ハッシュタグ**：1〜2個（#新NISA #ふるさと納税 #iDeCo #共働き #家計見直し #保険見直し）。
- **接点作り**：新婚・共働き・お金アカウントへ丁寧にリプライ（宣伝リプは避ける）。
- **制度スパイク**：改正・「年収の壁」等が話題化した当日に速報ポスト → 記事 → 診断（鮮度の堀）。
- **アフィリを含むリンクを貼る投稿はPR明示**（例：文中に「#PR」）。診断ページ自体はPRではないので不要。
- **NGワード/表現**：「必ず儲かる」「これを買え」等の断定・銘柄推奨、「FP」「アドバイザー」等の資格匂わせ、旧社名。
- **顔出しなし**：アイコンはロゴ/イラストで。
