# 手取りラボ｜リプ営業プレイブック（テンプレ＋ターゲット）

## A. リプ営業テンプレ集（そのまま/微調整で使う）

**黄金の型：①共感・肯定 → ②知見を1つだけ足す（制度／元営業の視点）→ ③宣伝しない。** 「へえ、この人詳しい」と思わせてプロフに来てもらえれば勝ち。リンクは貼らない。

### 保険（死亡・生命）
- 相手「保険どうしてる？／入るべき？」
  → `元保険の営業だったので一言だけ🙂 死亡保険は"遺された家族"のためのものなので、扶養する家族がいるかで必要額が大きく変わります。いないなら葬儀代くらいで足りることも。まず"必要保障額"から逆算すると迷わないですよ。`
- 相手「独身だけど保険入ってない、大丈夫？」
  → `扶養する家族がいないなら、大きな死亡保険は基本いらないことが多いです。備えるなら"働けないリスク"と生活防衛資金の方が先かもです。`

### 医療・がん保険
- 相手「医療保険って入っておくべき？」
  → `高額療養費制度で"1か月の自己負担に上限"があるので、ある程度の貯蓄があると民間の医療保険は過剰になりがち…って意外と知られてないですよね。まず公的制度を知ってから、が安心です。`
- 相手「がん保険どうしよう」
  → `会社員なら傷病手当金＋高額療養費で結構カバーされます。自営業・貯蓄が薄い人は必要度が上がる、と分けて考えると判断しやすいです。`

### 保険料・見直し
- 相手「保険料高い気がする…」
  → `"平均いくら"より"自分の必要保障額"で見ると、下がることが多いです。多すぎ/少なすぎが一目で分かるので。`
- 相手「保険見直したいけど何から」
  → `順番は「現状把握→必要保障額→過不足→調整」がラクです。結婚・出産・住宅購入は特に見直しどきですね。`

### NISA
- 相手「NISA何を買えばいい？」
  → `銘柄は人それぞれですが、"低コスト・分散・長期・続く金額"の4点で選ぶと大外ししにくいです。枠を埋めるより、続く額で長く、が結局強いなと🙂`
- 相手「NISA暴落こわい/やめたい」
  → `積立なら下落時は"安く買える月"でもあるので、生活防衛資金さえ分けておけば通過点にできます。狼狽売りだけ避けたいところですね。`

### iDeCo
- 相手「iDeCoやった方がいい？」
  → `節税は強力（掛金×税率）ですが、"原則60歳まで引き出せない"のが最大の注意点。当面使うお金はNISAへ、が安全です。`

### ふるさと納税
- 相手「ふるさと納税やってない/やり方むずい」
  → `先に限度額だけ確認すれば大丈夫です。超えた分は自己負担になるので、そこだけ注意すればほぼお得。共働きなら二人分の枠が使えます。`

### 年収の壁・家計
- 相手「年収の壁がなあ…」
  → `フルタイム共働きだと、実はあまり関係ないんですよね。効くのは時短・パート期。世帯・長期で見ると印象変わるかもです。`
- 相手「家計見直したい、何からやる？」
  → `効果が大きい順だと、固定費→保険→税（ふるさと/iDeCo/NISA）の順が多いです。細かい節約より固定費が効きます。`

### 汎用オープナー / クローザー
- オープナー：`横から失礼します🙂` / `元保険の営業だったので一言だけ…`
- クローザー：断定しない → `…というのが一般的ですが、状況で変わるので"自分はどうか"で見るのが確実です。`

### ❌ NG（やらない）
- リンクを貼る／「診断どうぞ」「詳しくはプロフ」→ 宣伝リプは即ミュートされる
- 上から目線・否定だけ・資格匂わせ（「FPとして」等）・断定・コピペ感

## B. 誰にリプする？（ターゲット選定と探し方）

### 選ぶ基準（この5つで絞る）
1. **フォロワー1,000〜5万の"中規模"**（メガは埋もれる、小さすぎは母数不足）
2. **エンゲージが活発**（リプ・いいねが実際に付いている）
3. **投稿頻度が高い**（毎日発信＝接点が多い）
4. **リプ歓迎の空気**（「どうしてる？」「教えて」「みんなは？」系が多い）
5. **投稿直後を狙う**（数分〜数十分以内の"早リプ"で上位表示されやすい）

### 毎日その場で見つける検索クエリ（X）
検索窓に入れて「最新」タブで拾う。`min_faves:` で"反応がある投稿＝人がいる"に絞れる。
- `共働き 家計 min_faves:20 lang:ja`
- `保険 見直し min_faves:10 lang:ja`
- `新NISA 何買う lang:ja` / `NISA 積立 いくら lang:ja`
- `iDeCo 迷う lang:ja` / `ふるさと納税 やり方 lang:ja`
- `貯金 できない lang:ja` / `お金 増やしたい lang:ja`
- ハッシュタグ巡回：`#共働き #家計管理 #家計簿 #新NISA #ふるさと納税 #保険見直し #プレママ #お金の勉強 #節約`

### ペルソナ別セグメント（狙う人物像）
1. **共働き・家計管理**（20〜40代・世帯の最適化に関心）
2. **新婚・プレママ/子育て**（結婚・出産でお金を見直す時期＝主砲と相性◎）
3. **お金初心者・節約**（貯金/固定費/ポイ活。優しく知見を足す）
4. **NISA/投資初心者**（「何買う」「積立いくら」で悩む層）
5. **保険の疑問を投げている人**（見直し・医療・がん保険）
6. **中規模のFP・お金解説アカウント**（相互交流・引用・丁寧なリプで関係構築）

### 例：広く知られた"大型アカウント像"（※活動・ハンドルは要確認）
- **お金教育の大型ブランド**（例：両学長／リベ大 系）＝リプ欄に人は多いが埋もれやすい → **メインは中規模の早リプ**、大型は"たまに良質リプ"程度に。
- **家計・節約系の主婦インフルエンサー**（世帯・共働き層と重なる）
- **NISA/投資初心者向けの解説アカウント**
> 特定@は変動するため、上の検索クエリで"今アクティブな中規模"を毎日拾うのが確実。良い人は **Xのリスト**（自作「リプ営業_家計」等）に入れて巡回。

### 毎日の回し方（15分ルーティン）
1. 上のクエリ/リストを開く（「最新」タブ）
2. 中規模×活発×投稿直後を、**5〜10件**選ぶ
3. 各に**Aの型で価値あるリプ**（宣伝しない）
4. 良かった相手はリストに追加。相手からの反応・フォローを翌週の配分に反映
5. 目安 **1日10〜20リプ**（自分の投稿より優先）

> 効くのは"量×質×早さ"。バズより、毎日の良質な10リプが最初のフォロワーを連れてきます。
